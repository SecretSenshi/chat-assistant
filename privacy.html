プライバシーポリシー

ChatAssistant（以下「本アプリ」）は、開発者本人だけが自分の PC で使う個人用アプリです。

  • 本アプリは、本人が許可した Google アカウントの Google カレンダーと Google ToDo リストのデータを、予定の表示・リマインド・予定やタスクの追加のためだけに読み書きします。
  • 取得したデータは本人の PC 内にのみ保存し、第三者に販売・共有・送信しません。広告や分析には使いません。
  • Google API から受け取ったデータの利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。
  • アクセスは Google アカウントの「サードパーティのアクセス」からいつでも取り消せます。取り消すと本アプリは新たなデータを取得できなくなります。

Privacy Policy

ChatAssistant is a personal app used only by its developer on their own PC. It reads and writes the authorizing user's Google Calendar and Google Tasks solely to display schedules, send reminders and add events/tasks. Data stays on the owner's PC and is never sold, shared or transferred to third parties, and is not used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account's third-party access settings.
